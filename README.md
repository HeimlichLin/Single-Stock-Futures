# 📈 全市場股期即時看板 - 安裝與操作手冊

## 🚀 快速開始 (Quick Start)

如果您已經熟悉 Python，請直接執行以下指令：

```bash
# 1. 安裝套件
pip install -r requirements.txt

# 2. 啟動伺服器
python app.py
```

然後打開瀏覽器訪問 `http://127.0.0.1:5000` 即可。

---

## 1. 環境準備 (Prerequisites)

在開始之前，請確保您的電腦已經安裝了 Python 環境。

### **步驟一：安裝 Python**
*   **若尚未安裝**：請前往 [Python 官網](https://www.python.org/downloads/) 下載最新版本 (建議 3.7 以上)。
*   **注意**：安裝時，務必勾選 **"Add Python to PATH"** (將 Python 加入環境變數)，這樣才能在黑視窗直接執行指令。

### **步驟二：安裝必要的 Python 套件**
這個程式依賴三個外部套件：`Flask` (架設網頁)、`requests` (下載清單)、`aiohttp` (光速爬蟲)。

請打開您的 **命令提示字元 (CMD)** 或 **PowerShell**，切換到專案目錄，輸入以下指令並按 Enter：

```bash
pip install -r requirements.txt
```

*等待跑完，出現 Successfully installed... 即完成。*

---

## 2. 程式部署 (Deployment)

### **步驟三：下載專案檔案**
請確保您的專案資料夾結構如下：

```text
Single-Stock-Futures/
├── app.py              # [入口] Flask 伺服器啟動與路由設定
├── scraper.py          # [邏輯] 爬蟲核心邏輯 (AsyncIO, 資料處理)
├── config.py           # [設定] 常數設定 (月份代碼, 名稱對照)
├── requirements.txt    # [依賴] 套件清單
├── README.md           # [文件] 說明檔
└── templates/          # [畫面] 存放 HTML 檔案
    └── index.html      # 前端介面 (包含 CSS 與 JS)
```

確保所有檔案都已正確放置在對應的位置。

## 3. 啟動與操作 (Operation)

### **步驟四：執行程式**
1.  在存放 `app.py` 的資料夾中，在空白處按住 `Shift` + `滑鼠右鍵`，選擇「**在此處開啟 PowerShell 視窗**」或「**命令提示字元**」。
2.  輸入以下指令並執行：
    ```bash
    python app.py
    ```
3.  當您看到類似以下的訊息，代表伺服器已成功啟動：
    ```text
    * Serving Flask app 'app'
    * Debug mode: off
    * Running on http://127.0.0.1:5000
    [系統] 下載清單中...
    [系統] 下載成功，共 xxx 檔
    ```

### **步驟五：開始看盤**
1.  打開您的瀏覽器（Chrome / Edge / Firefox）。
2.  在網址列輸入：`http://127.0.0.1:5000`
3.  進入網頁後，點擊右上角的 **「⚡ 開始掃描」** 按鈕。
4.  **享受成果**：
    *   資料會像流水一樣飛快載入（約 5-10 秒內掃描全市場）。
    *   **自動排序**：股票代號 (2330) > 大小台 (大台在前) > 月份 (近月在前)。
    *   **即時搜尋**：在上方搜尋框輸入「台積」或「2330」，會即時篩選顯示。

## 4. 功能特色總結 (Features)

這個版本解決了所有先前遇到的技術難題，是目前最穩定、最強大的版本：

1.  **免 API Key、免登入**：
    *   直接模擬瀏覽器行為爬取 Yahoo 網頁，完全繞過 API 500 錯誤或權限驗證。
2.  **系統時間自動化**：
    *   程式會讀取您電腦的時間（即使是 2025 年），自動推算出正確的合約代碼（當月與下月）。
3.  **光速非同步技術 (AsyncIO)**：
    *   使用 `aiohttp` 技術，同時開啟 **40 條連線** 並發爬取，速度比傳統爬蟲快 20 倍以上。
4.  **智能排序 (Smart Sorting)**：
    *   前端採用「插入排序法」，確保資料載入順序雖不同，但顯示時永遠是 **「同公司的期貨排在一起」**。
5.  **資料完整性**：
    *   自動從期交所 Open Data 抓取最新清單，包含大台、小台所有標的。

## 5. 常見問題排除 (Troubleshooting)

*   **Q: 執行 `pip install` 時出現錯誤？**
    *   A: 請確認您是否已安裝 Python，且安裝時有勾選 "Add to PATH"。如果還是不行，試著用 `python -m pip install aiohttp flask requests`。
*   **Q: 點擊開始掃描後，卻沒有資料跑出來？**
    *   A: 請檢查黑色視窗是否有紅色的錯誤訊息。如果是 Yahoo 連線問題，可能是短時間內請求太頻繁被暫時阻擋，請等待 1 分鐘後再試。
*   **Q: 為什麼我的電腦顯示是 2025 年？**
    *   A: 這是您電腦的系統時間設定。本程式已經能夠相容您的 2025 年設定，會自動去抓 Yahoo 對應的未來合約（如果 Yahoo 有開的話），或者您可以手動將電腦時間調回正確年份。
*   **Q: 怎麼關閉程式？**
    *   A: 回到那個黑色的視窗，按下鍵盤的 `Ctrl + C` 即可停止伺服器。
